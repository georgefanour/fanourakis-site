# Επεξεργασία περιεχομένου

## Σχετικά
Επεξεργάσου το `content/el/about.json`. Άλλαξε μόνο την τιμή του `text` και κάνε Commit changes.

## Στίχοι και κείμενα
Επεξεργάσου το `content/el/texts.json`. Κάθε καταχώριση έχει `id`, `title` και `body`. Για νέο κείμενο, αντέγραψε ένα υπάρχον αντικείμενο μέσα στο `lyrics` ή στο `writings`, δώσε μοναδικό `id`, τίτλο και σώμα κειμένου. Κάνε Commit changes.

## Αγγλικά
Τα αντίστοιχα αγγλικά αρχεία είναι `content/en/about.json` και `content/en/texts.json`.

Σημαντικό: κράτησε τα εισαγωγικά και τα κόμματα του JSON όπως είναι. Για νέα γραμμή μέσα σε κείμενο χρησιμοποίησε `\n`.
